# SmartFinance CRM —— 金融产品智能推荐系统

## 1. 项目简介

SmartFinance CRM 是一个基于 Python 和 Streamlit 开发的金融产品智能推荐系统。

本项目通过分析客户的基本信息和风险偏好，结合金融产品的风险等级，利用风险匹配评分算法计算客户与不同金融产品之间的匹配程度，并根据匹配分数生成个性化推荐结果。

系统采用交互式 Web 页面，用户可以选择不同客户，查看客户信息、金融产品信息以及对应的推荐结果。

本项目主要用于课程实验和智能推荐系统的基础功能演示。

## 2. 项目功能

本系统主要实现以下功能：

### 2.1 客户信息管理

- 从 CSV 文件读取客户数据。
- 支持通过下拉框选择客户。
- 展示客户编号、年龄、年收入和风险偏好。

### 2.2 金融产品展示

系统展示不同类型的模拟金融产品，包括：

| 产品名称 | 产品类型 | 风险等级 |
|---|---|---|
| 稳健理财A | 银行理财 | 低风险 |
| 指数基金B | 基金 | 中风险 |
| 黄金积存C | 贵金属 | 中风险 |
| 成长基金D | 基金 | 高风险 |

### 2.3 智能推荐

根据客户风险偏好和金融产品风险等级，计算匹配分数，并按照分数从高到低进行排序。

### 2.4 推荐结果分析

展示不同金融产品的匹配分数、推荐排序及推荐理由，帮助用户理解系统的推荐结果。

## 5. 环境配置

### 5.1 Python 环境

本项目使用 Python 3.12。

首先进入项目根目录：

```powershell
cd SmartFinance-CRM
```

创建虚拟环境：

```powershell
py -3.12 -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5.2 安装项目依赖

项目的 `requirements.txt` 内容：

```text
streamlit>=1.40.0

```

使用清华大学 PyPI 镜像安装依赖：


## 8. 推荐算法设计

### 8.1 风险等级数值映射

为了便于计算，系统将客户风险偏好和产品风险等级转换为数值。

| 风险等级 | 风险评分 |
|---|---:|
| 低风险 | 1 |
| 中风险 | 3 |
| 高风险 | 5 |

### 8.2 匹配分数计算

系统通过客户风险评分与产品风险评分之间的差异计算匹配程度。

计算公式：

\[
MatchScore = 100 - |CustomerRiskScore - ProductRiskScore| \times 20
\]

其中：

- CustomerRiskScore：客户风险评分。
- ProductRiskScore：金融产品风险评分。
- MatchScore：客户与金融产品之间的匹配分数。

匹配分数越高，表示客户风险偏好与产品风险等级越接近。

### 8.3 推荐示例

假设某客户的风险偏好为低风险，其风险评分为 1。

不同金融产品的匹配分数如下：

| 金融产品 | 产品风险评分 | 匹配分数 |
|---|---:|---:|
| 稳健理财A | 1 | 100 |
| 指数基金B | 3 | 60 |
| 黄金积存C | 3 | 60 |
| 成长基金D | 5 | 20 |

系统根据匹配分数进行降序排序，优先展示匹配分数较高的产品。

## 10. 项目总结与改进方向

本项目实现了一个基于客户风险偏好的金融产品智能推荐系统，完成了客户数据读取、金融产品展示、风险匹配评分和推荐结果分析等基础功能。

当前系统采用规则评分算法，具有逻辑简单、计算方便和推荐结果易于解释等特点。

但目前的推荐依据主要是客户风险偏好与产品风险等级，尚未综合考虑客户投资期限、资金规模、流动性需求、收益目标以及历史投资行为等因素。

后续可以在现有系统基础上增加多维度客户特征和产品属性，进一步完善推荐算法，提高推荐结果的合理性。
